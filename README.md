# Web Extension (dev & publish)

Group project for the Web 3 course (HE Vinci).
This repository contains the two Chrome extensions shown in our video.

## Contents

- [`hello-world-extension/`](hello-world-extension): the smallest possible extension, to learn the basics. Start here.
- [`anti-procra/`](anti-procra): a more complete extension that uses the 4 main parts of an extension (manifest, popup, content script, service worker).

Each folder has its own README explaining how to run it.

## Running an extension

1. Clone this repository.
2. Open `chrome://extensions` and turn on **Developer mode**.
3. Click **"Load unpacked"** and select one of the two folders.

Also works on Edge (`edge://extensions`) and Brave.
