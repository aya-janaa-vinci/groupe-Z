# Hello World: Chrome Web Extension

Group project for the Web 3 course (HE Vinci): **Web Extension (dev & publish)**.
Based on the [official Chrome tutorial](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world).

## Running the extension

1. Clone this repository.
2. Open `chrome://extensions` and turn on **Developer mode**.
3. Click **"Load unpacked"** and select this folder.
4. Click the extension icon: a popup shows "Hello Extensions".
